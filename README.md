# Уроженцы Орского уезда в документах Первой мировой войны, 1914–1918

**Версия 2.0: 20 473 персональные записи** о жителях Орского уезда Оренбургской
губернии в документах русской армии 1914–1918 годов: госпитальные карточки,
донесения о потерях, награждения, плен. С местом рождения, архивными шифрами
РГВИА и ссылками на сканы.

*Natives of Orsk uyezd (Orenburg governorate) in Russian WWI records, 1914–1918.
Version 2.0: 20,473 records, whole uyezd, with RGVIA archival references and
links to document scans. Derived dataset, CC BY 4.0.*

### 2.1: волости нормализованы

2 762 написания волостей сведены к 58 каноническим (`волость_норм`, исходная
колонка `волость` не тронута). **14 016 из 16 367 записей (85,6 %)**:
- кодом (`scripts/normalize-volost.py`): номер вынимается отдельно, в том числе
  словом («Вторая», «Пятая»), основа сравнивается с каноническим списком по
  Левенштейну (порог 85) и по словарю явных синонимов — 13 412 записей;
- хвост — классификатором **Jev** (TypeSafe System One, `scripts/volost-jev.py`):
  он не генерирует текст, а выбирает одну из канонических волостей или «другое»
  с вероятностью. Принят ответ с вероятностью ≥ 0,8 — 604 записи. Ниже порога
  Jev ошибается («Павловская» → Покровская, 0,42), такие оставлены пустыми.
  Все ответы с вероятностями — `derived/v2/volost-jev.json`.

В `волость_сходство` видно, откуда значение: число 85–100 — сходство, `jev 0.93` —
ответ классификатора. Таблица всех написаний — `derived/v2/volost-variants.csv`.

Производные таблицы по v2 — в `derived/v2/` (варианты написаний, гнёзда,
помесячная хронология, части, привязка к координатам). Таблицы в `derived/` —

## Что это и зачем

По Первой мировой почти не ведётся генеалогическая работа: поиск идёт в
документы 1941–1945 годов. Между тем карточки 1914–1918 содержат **привязку к
деревне** — редкость для источников этого периода. Между X ревизией 1859 года
и советскими переписями населённый пункт рождения фиксируют немногие
документы, и для части семей такая карточка — единственное упоминание предка
за шестьдесят лет.

## Данные

`data/pmv-orsk-uezd-1914-1918.csv` — UTF-8, 1368 строк, 15 полей:
фамилия, имя, отчество, чин, часть, причина выбытия, дата, волость,
населённый пункт, архив, фонд, опись, дело, тип документа, id записи.

**По полю «дело» заказывается сам документ в РГВИА** — это главное, что
сохраняет ценность датасета независимо от доступности портала-источника.

а не бои; пропавших без вести **вдвое больше, чем убитых** — для семьи это
означало не похоронку, а неизвестность.

### Справочник и эталон

`reference/` — то, чем свод **проверяется**:

- **`gazetteer.csv`** — 4634 населённых пункта территории уезда из OSM (2965)
  и Wikidata (1669). ⚠️ Лицензии источников — ODbL и CC0, они **не совпадают**
  с лицензией репозитория; колонка «источник» обязательна к сохранению.
- **`gold-pairs.csv`** — 628 пар написаний с меткой «одно и то же», размеченных
  справочником, а не той мерой, которую выборка проверяет.

Это и есть главный сдвиг версии 1.2: пороги и меры сходства теперь выбираются
измерением. Замена меры подняла полноту с 0,284 до 0,370 при меньшей доле
ложных склеек; отвергнутые критерии и границы метода — в `derived/benchmark.md`.

Из 661 написания к точке на карте привязались 157, то есть **300 записей свода
получили координаты**. Остальные три четверти селений на карте не значатся —
их больше нет.

### Один человек в нескольких документах

В донесении «Манкаманов Абдул Абтрахимов», в госпитальной карточке
«Мелкоманов Абдула Абрахимов» — деревня одна, человек один, а точный ключ
видит двоих. `scripts/duplicates.py` ищет такие пары моделью Феллеги—Санта с
оценкой параметров через EM: **размеченная выборка ей не нужна**, она
оценивает по самим данным, насколько согласие по каждому полю характерно для
пар «один человек».

Самое надёжное поле оказалось не фамилия, а **отчество** (вес +5,01 против
+1,93): у тюркских имён писари перевирали прежде всего фамилию. Если верить
парам от 0,99 — 1368 записей соответствуют примерно **1227 персонам**.

Это кандидаты на проверку по архивному делу, а не утверждение; чего модель не
умеет — `docs/record-linkage.md`.

```bash
python3 scripts/gazetteer.py     # собрать справочник (сеть: Overpass + WDQS)
python3 scripts/reconcile.py     # привязать написания к сёлам
python3 scripts/goldstandard.py  # пересобрать эталон
uv run scripts/benchmark.py      # сравнить меры сходства
python3 scripts/duplicates.py    # найти вероятные дубли персон
```

**Зачем гнёзда.** Писарь записывал башкирское название на слух, и одно село
расходится по картотеке под шестью именами:

> Бикбердина · Верхняя Бикберда · Верхне-Бикберд · Нижний Биг-Бирд ·
> Нижне-Бигберды · Нижняя Бикберда

Ищущий по современному написанию находит одну запись из шести. Метод, пороги и
чего он **не** умеет — `docs/spelling-variants.md`. Гнездо там — гипотеза с
выписанной мерой сходства, а не установленный факт.

## Как отобрано: 1368 из 9920

Поиск на портале-источнике ведётся по названию волости и **ловит однофамильные
волости по всей империи**.

| этап | записей |
|---|---|
| выгружено по двум запросам | 9920 |
| без указания места рождения | −6751 (68 %) |
| чужие волости-тёзки | ≈ −1780 |
| Оренбургская губ., Орский уезд | 1386 |
| после дедупликации | **1368** |

Отсеяны: Галаховская волость Саратовской губернии, Салиховская Самарской,
Селиховская Тверской и Орловской. По названию волости они неотличимы —
различают только губерния и уезд.

⚠️ **Практический вывод для тех, кто повторит:** фильтровать по губернии и
уезду, а не по названию волости. Проверка показала записи, где волость набрана
с опечаткой («Селиховская», «Салифовская»), но уезд указан верно, а деревни в
них — Худайбердино и Чупаново, обе из Салиховской волости Орского уезда.
Фильтр по названию их потерял бы.

## Ограничения

1. **Это не полный список участников войны из уезда.** Две трети исходных
   карточек не содержат места рождения. Отсутствие человека здесь не означает,
   что он не служил.
2. **Отражены потери, а не призыв.** Прошедший войну без ранений и болезней в
   такие документы не попадал.
3. **Написание имён источниковое.** Тюркские имена передавались на слух; одна
   фамилия встречается в нескольких вариантах. Искать следует перебором:
   мягкий знак, удвоение согласной, е/ё/и, окончания -ов/-ев.
4. **Дедупликация** может склеить полных тёзок из одного селения и наоборот —
   сохранить дубль при разночтении в названии части.
5. Названия селений даны в форме источника, без приведения к современным.

## Источник и права

Исходные сведения опубликованы на портале «Памяти героев Великой войны
1914–1918» (`gwar.mil.ru`, Минобороны РФ) по документам РГВИА.

**Факты — имена, даты, номера дел — не являются объектом авторского права.**
Настоящий свод является производной работой: отбор, очистка от однофамильных
волостей, дедупликация и структурирование выполнены составителем. Копией
базы-источника он не является.

Датасет распространяется по лицензии **CC BY 4.0**. При использовании
желательна ссылка на первоисточник и на этот свод.
