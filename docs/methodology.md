# Уроженцы Орского уезда Оренбургской губернии в документах о потерях Первой мировой войны: свод и анализ

**Черновик описания датасета (data paper).** Составлено 12.09.2026.

## Аннотация

Представлен свод из **1368 персональных записей** об уроженцах Орского уезда
Оренбургской губернии, отражённых в документах о потерях русской армии
1914–1918 годов. Источник — оцифрованные материалы РГВИА, опубликованные на
портале «Памяти героев Великой войны 1914–1918». Описаны методика отбора,
структура данных и ограничения. Отдельно рассмотрена проблема
**однофамильных волостей**, из-за которой поиск по названию волости даёт долю
постороннего материала, превышающую долю целевого.

## 1. Постановка

Документы Первой мировой войны остаются наименее востребованным массовым
источником по генеалогии населения Урала. Исследовательский интерес и
поисковая активность сосредоточены на материалах 1941–1945 годов, тогда как
призыв 1914 года даёт **деревенскую привязку**, редкую для документов этого
периода: между X ревизией 1859 года и советскими переписями населённый пункт
рождения фиксируется немногими источниками.

Для значительной части семей карточка о ранении или болезни оказывается
единственным документальным упоминанием человека за шестьдесят лет.

## 2. Источник и метод

Материал получен сплошной выгрузкой по двум поисковым запросам к порталу
(волости Салиховская и 2-я Усерганская Орского уезда). Получено 9920 карточек.

Дальнейшая обработка:

| Этап | Записей |
|---|---|
| выгружено | 9920 |
| **исключены без места рождения** | −6751 (68 %) |
| **исключены однофамильные волости** | ≈ −1780 |
| отобрано: Оренбургская губ., Орский уезд | 1386 |
| после дедупликации | **1368** |

**Проблема тёзок.** Запрос по названию волости возвращает совпадения по всей
империи. В выгрузку попали Галаховская волость Саратовской губернии,
Салиховская Самарской, Селиховская Тверской и Орловской губерний. По названию
волости они неотличимы; единственный надёжный различитель — губерния и уезд.
Доля постороннего материала в исходной выгрузке превысила долю целевого.

Дедупликация проведена по связке «фамилия + имя + отчество + населённый
пункт + воинская часть»: один человек присутствует в нескольких документах
(донесение, госпитальная карточка).

## 3. Результаты

**Объём и охват.** 1368 записей; у 888 (65 %) указан населённый пункт;
представлен **661 населённый пункт** и **424 воинские части**.

**Распределение по годам** (по дате события):

| 1914 | 1915 | 1916 | 1917 | 1918–19 |
|---|---|---|---|---|
| 49 | 330 | **529** | 280 | 2 |

Максимум приходится на 1916 год.

**Структура выбытия:**

| Причина | Записей | Доля |
|---|---|---|
| ранен / контужен | 658 | 48,1 % |
| **болен** | 333 | **24,3 %** |
| пропал без вести | 155 | 11,3 % |
| не уточнено | 79 | 5,8 % |
| убит | 66 | 4,8 % |
| оставлен на поле боя | 63 | 4,6 % |
| попал в плен | 4 | 0,3 % |

Два наблюдения заслуживают отдельного упоминания.

**Болезнь составляет почти четверть выбытий** — сопоставимо с половиной доли
боевых ранений. Это отражает санитарные условия театра военных действий, а не
только боевые потери.

**Пропавших без вести (11,3 %) более чем вдвое больше, чем убитых (4,8 %).**
Расхождение характерно для учёта потерь этой войны: гибель при отступлении
или в окружении фиксировалась как пропажа без вести, и для семьи означала
отсутствие определённости в судьбе.

**Рассеяние по частям.** 424 соединения на 1368 человек: в среднем на часть
приходится трое. Землячества как правила не было — но и полного распыления
тоже. Несколько полков заметно выделяются: 306-й пехотный Мокшанский — 49
уроженцев уезда, 212-й Романовский — 36, 190-й Очаковский — 35, 9-й Сибирский
стрелковый — 33. На фоне медианы в одного человека (256 частей из 424 представлены
единственным уроженцем уезда) это следы того, что
маршевые роты уездного присутствия уходили пополнением в одни и те же части.

## 3-бис. Хронология выбытия

Помесячный ряд (`derived/monthly.csv`, график — `derived/monthly.svg`)
построен по 1190 записям, где дата указана; у 178 её нет.

| Месяц | Записей | Что преобладает |
|---|---|---|
| 1915-05 | 50 | оставлено на поле боя — 24, пропало без вести — 13 |
| 1916-06 | **108** | ранено — 80 |
| 1916-07 | 89 | ранено — 68 |
| 1917-05 | 39 | больных — 31, боевых потерь почти нет |

Три пика совпадают по времени с известными событиями кампаний, и структура
выбытия в каждом различна. Май 1915 — время Горлицкого прорыва и отхода: три
четверти записей месяца это «оставлен на поле боя» и «пропал без вести», то
есть потери отступающей армии, которая не выносит раненых и не хоронит убитых.
Лето 1916 даёт вдвое больший вал, но почти целиком из ранений — потери
наступающих. Май 1917 не даёт боевых потерь вовсе: остаются больные.

Такое распределение делает свод пригодным не только для поиска предка. Доля
«оставлен на поле боя» в общем ряду — 4,6 %, но внутри мая 1915 года она
достигает 48 %, и этот перепад виден на выборке одного уезда.

## 3-тер. Гнёзда написаний

Тюркские названия и имена записывались писарями на слух. Одно село
встречается в картотеке под шестью написаниями: Бикбердина, Верхняя Бикберда,
Верхне-Бикберд, Нижний Биг-Бирд, Нижне-Бигберды, Нижняя Бикберда. Поиск по
современной форме находит одну запись из шести.

К своду приложен словарь гнёзд: написания сводятся к фонетическому скелету
(свёртки п↔б, к↔г, т↔д, ш↔с и прочие), раскладываются по корзинам согласного
костяка и группируются вокруг самого частого написания мерой
Рэтклиффа—Обершелпа при пороге 0,84 (для фамилий 0,88).

| | |
|---|---|
| различных написаний населённых пунктов | 661 |
| гнёзд после объединения | 552 |
| гнёзд из двух и более написаний | 74 |
| гнёзд фамилий из нескольких написаний | 62 |

Объединение **не транзитивное**: каждый вариант сравнивается с заголовком
гнезда, а не с соседом по цепочке. Первая версия объединяла по цепочке и
связала фамилии «Гайсин» и «Хасанов» через «Хасинова». Плата за отказ —
дробление: «Бикбердина» и «Нижне-Бикбирде» остались двумя гнёздами, хотя это
одно село. Из двух ошибок эта дешевле: лишнее гнездо ищущий пролистает,
ложную склейку примет за факт.

Мера сходства выписана в каждой строке, поэтому слабые гнёзда отсеиваются
читателем без доверия к порогу. Метод и его ограничения — `spelling-variants.md`.

## 4. Ограничения

0. **Гнёзда написаний — гипотеза, а не факт.** Мера сходства выписана в
   таблицах; слабые гнёзда видны и отсеиваются. Разные сёла с похожими
   названиями метод не различает — он работает со звучанием, не с географией.
1. Свод **не является полным списком участников войны из уезда**. Две трети
   исходных карточек не содержат места рождения; отсутствие человека в своде
   не свидетельствует о том, что он не служил.
2. Отражены **потери, а не призыв**: прошедший войну без ранений и болезней в
   документы такого рода не попадал.
3. **Написание имён источниковое.** Тюркские имена передавались на слух, одна
   фамилия встречается в нескольких вариантах; поиск требует перебора
   написаний.
4. Дедупликация способна как склеить полных тёзок из одного селения, так и
   сохранить дубль при разночтении в названии части.
5. Названия селений приведены в форме источника без приведения к современным.

## 5. Значение

Свод даёт исследователям и потомкам **прямой переход от имени к архивному
делу**: каждая запись содержит шифр РГВИА, по которому заказывается документ.
Это сохраняет ценность независимо от доступности портала-источника.

Отдельным результатом является описанная методика отсева однофамильных
волостей: при работе с порталом она применима к любому уезду и, судя по
соотношению 1386 к 9920, необходима.

## Доступ

Датасет: `data/pmv-orsk-uezd-1914-1918.csv` (UTF-8, 1368 записей, 15 полей).
Производные таблицы — `derived/`, пересобираются `scripts/analyze.py`.
Скрипт выгрузки — `scripts/gwar-sweep.py`.

### Заметки для доработки перед публикацией

- добавить сведения об авторе и аффилиации (или указать независимого исследователя);
- выбрать лицензию: предпочтительно **CC BY 4.0** для свода;
- проверить, нет ли среди записей сведений, требующих осторожности (все лица
  умерли более ста лет назад — ограничений по персональным данным нет);
- при подаче на Zenodo указать ключевые слова: Первая мировая война, РГВИА,
  Оренбургская губерния, Орский уезд, генеалогия, башкиры, потери;
- возможное расширение: выгрузка по остальным волостям уезда даст, по оценке,
  несколько тысяч записей и позволит сравнение между волостями.
